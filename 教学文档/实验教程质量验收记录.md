## 一、验收原则

本次验收不以“单个最终版本能够运行”作为唯一标准，而是按学生实际学习顺序，从空目录开始连续执行 D00—D16。每个检查点同时核对文件变化、页面或接口结果、业务数据和自动测试，避免出现“每个快照单独可用，但从前一版本升级失败”的问题。

标准运行条件如下：

1. Windows 10 或 Windows 11，64 位；
2. Python 3.11.x；
3. 首次安装依赖时能够联网；
4. 课程资源目录与个人工作目录分开；
5. 全程使用同一个数据盘和同一个个人工作目录。

## 三、跨版本数据升级专项验收

连续复现时发现并修复了一项跨版本缺陷：旧实现能够保留 D10 的预约记录，但不会为旧记录补建状态历史，导致学生到 D12 时看到的历史数量少于手册描述。

修复后的专项结果如下：

1. D10 的待审批记录升级到 D11 后，预约编号、申请内容和状态均保留，并自动补建“提交预约”历史；
2. 上述记录在 D12 通过后，时间线依次包含“提交预约”和“审批通过”两条记录；
3. D10 已取消记录升级到 D11 后，时间线依次包含“提交预约”和“取消预约”两条记录；
4. 重复启动 D11—D16 不会重复补建相同状态历史；
5. 修复已同步到 D11—D16 逐步代码、`dev-v0.5`、`dev-v0.6`、`dev-v1.0` 冻结终点和仓库根目录最终程序。
