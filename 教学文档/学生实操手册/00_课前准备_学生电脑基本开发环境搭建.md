# 实验准备　学生电脑基本开发环境搭建（Windows）

| 项目 | 内容 |
|---|---|
| 适用系统 | Windows 10 / Windows 11，64 位 |
| 建议用时 | 30—45 分钟 |
| 准备起点 | 能够联网、尚未配置课程环境的个人电脑 |
| 准备终点 | D00 起点文件、项目虚拟环境和规定依赖全部验收通过 |

## 0.1 准备目标

本课程从 D00 开始逐步完成“校园实验室预约与审批系统”。在复制第一个代码文件之前，必须先让电脑具备统一、可检查、可恢复的基本开发环境。

本次准备的起点和终点如下：

- 起点：一台能够联网的 Windows 笔记本，可能尚未安装任何开发软件。
- 终点：电脑能够使用 Python 3.11、Visual Studio Code 和 Git；课程资源与个人工作目录已经分开；`D:\campus-lab-work\.venv\Scripts\python.exe` 能够运行，并且其中已经安装课程指定版本的 Flask 和 pytest。
- 本阶段不开发业务功能，也不会出现系统网页。D01 才会创建第一个 `app.py` 并看到网页。

应在第一次上课前完成。安装软件和第一次下载 Python 依赖时需要网络。

正常情况下只做七件事：

```text
安装并检查 Python 3.11
→ 安装 VS Code
→ 安装并检查 Git
→ 下载课程资源到 D:\campus-lab-course
→ 建立 D:\campus-lab-work
→ 复制 D00 的三个文件并双击初始化
→ 核对 Python、Flask 和 pytest 版本
```

0.10 节是遇到错误时才查阅的故障处理，不是每个人都要逐项操作。

## 0.2 环境组成与目录约定

### 0.2.1 需要的软件

| 软件 | 课程统一要求 | 在本课程中的用途 | 是否必需 |
|---|---|---|---|
| Python | 3.11.x，64 位 | 创建虚拟环境、运行 Flask、执行测试 | 必需 |
| Visual Studio Code | Windows User Installer | 查看完整代码文件、打开项目文件夹和终端 | 必需 |
| Git for Windows | 使用官方安装程序，默认选项即可 | 下载课程仓库，后续学习版本管理 | 必需 |
| 浏览器 | Edge 或 Chrome | 访问本机运行的系统 | 必需 |

推荐使用 Python 3.11.9 的 64 位 Windows 安装程序。电脑中已经有其他 Python 版本时，不需要卸载；可以并行安装 Python 3.11，本项目脚本会优先使用 `py -3.11`。

### 0.2.2 不需要安装的软件

本项目采用 Flask、Jinja2、SQLite 技术路线，不需要安装以下软件：

- Java、JDK、Maven；
- Node.js、npm、Vue；
- MySQL、SQL Server或其他数据库服务器；
- Docker；
- Anaconda。

SQLite 数据库由程序在本地文件中自动创建，不需要单独安装数据库管理软件。

### 0.2.3 两个目录必须分开

课程统一使用两个目录：

```text
D:\campus-lab-course    教师提供的课程资源，只复制、只核对，不在其中开发
D:\campus-lab-work      学生个人项目，D00—D16的所有操作都在这里完成
```

本手册、课堂演示和截图统一以 `D:` 为标准。电脑没有 D 盘时，应在上课前选择另一个可写的数据盘，例如 `E:`，并把手册命令中的盘符统一替换；两个子目录名称保持不变。不要一部分步骤使用 D 盘、另一部分步骤使用其他盘。只有电脑确实没有其他数据盘时，才把 C 盘作为例外。

不要直接修改 `D:\campus-lab-course\教学资源\逐步开发代码` 中的文件。个人项目发生错误时，这些完整文件是恢复依据。

## 0.3 安装并检查 Python 3.11

### 0.3.1 下载安装程序

打开 Python 官方页面：

- [Python 3.11.9 官方发布页](https://www.python.org/downloads/release/python-3119/)

在页面的“Files”区域选择“Windows installer (64-bit)”。不要选择 embeddable package，也不要下载源代码压缩包。

### 0.3.2 安装时确认关键选项

1. 双击安装程序。
2. 在第一个安装界面勾选 `Add python.exe to PATH`。
3. 选择 `Install Now`。
4. 等待安装完成后关闭安装窗口。
5. 关闭以前打开的命令窗口，再重新打开“命令提示符”。

### 0.3.3 检查 Python

按 `Win+R`，输入 `cmd`，按回车。依次执行：

```bat
py -3.11 --version
py -3.11 -m pip --version
```

第一条命令应显示：

```text
Python 3.11.x
```

其中最后一位修订号可以不同，例如 `Python 3.11.9`。第二条命令只要能够显示 pip 版本和安装路径即可。

如果提示“`py` 不是内部或外部命令”，再执行：

```bat
python --version
```

如果 `py` 和 `python` 都无法使用，请不要继续后面的步骤，先查看 0.10 节“故障排查与恢复”。

## 0.4 安装 Visual Studio Code

打开官方安装说明：

- [Visual Studio Code Windows 安装说明](https://code.visualstudio.com/docs/setup/windows)

推荐选择 Windows User Installer。它安装在当前用户目录，通常不要求管理员权限。

安装时保留默认选项，并确认启用以下两项：

- Add to PATH；
- Add “Open with Code” action（如果安装界面提供该选项）。

安装后启动 Visual Studio Code。当前阶段不要求安装任何扩展；后续即使 Python 扩展暂时不可用，也不影响通过批处理脚本运行项目。

## 0.5 安装 Git for Windows

打开官方页面：

- [Git for Windows 官方安装页](https://git-scm.com/install/windows)

下载 x64 Setup，运行安装程序。非计算机专业初学者保留默认选项即可，不需要在安装过程中修改分支名、终端或换行符等高级设置。

安装完成后，重新打开命令提示符，执行：

```bat
git --version
```

应看到类似结果：

```text
git version 2.x.x.windows.x
```

本节只确认 Git 能够使用，不设置用户名和邮箱，也不执行提交；版本管理会在后续内容中单独讲解。

## 0.6 取得课程资源

课程仓库地址：

- [https://github.com/bitpt00/wdproject](https://github.com/bitpt00/wdproject)

推荐使用方法 A。Git 或校园网络暂时不可用时，使用方法 B。

### 0.6.1 方法 A：使用 Git 下载

打开命令提示符，执行：

```bat
cd /d D:\
git clone https://github.com/bitpt00/wdproject.git campus-lab-course
```

完成后检查：

```bat
dir D:\campus-lab-course\教学资源\逐步开发代码\D00_S0起点
```

应当看到三个文件：

```text
.gitignore
requirements.txt
初始化开发环境.bat
```

如果 `D:\campus-lab-course` 已经存在，不要在同一个目录中再次执行 `git clone`。先确认它是否是以前下载的课程资料；课堂更新时再按教师要求执行 `git pull`。

### 0.6.2 方法 B：下载 ZIP

1. 用浏览器打开课程仓库。
2. 点击绿色 `Code` 按钮。
3. 点击 `Download ZIP`。
4. 下载完成后必须完整解压，不要在压缩包预览窗口中操作。
5. 把解压后的仓库文件夹改名为 `campus-lab-course`，并放到 `D:\` 下。
6. 检查最终路径是否为：

```text
D:\campus-lab-course\教学资源\逐步开发代码\D00_S0起点
```

如果路径中出现 `wdproject-main\wdproject-main` 两层同名目录，应进入真正包含 `README.md` 和 `教学资源` 的内层目录，再整理为上述路径。

## 0.9 环境验收

“脚本运行过”不等于环境一定正确。请打开命令提示符，依次执行下面的命令。

### 0.9.1 进入个人工作目录

```bat
cd /d D:\campus-lab-work
dir /a
```

`dir /a` 的结果中必须能看到 `.venv`、`.gitignore`、`requirements.txt` 和 `初始化开发环境.bat`。

### 0.9.2 检查项目使用的 Python

```bat
.venv\Scripts\python.exe --version
.venv\Scripts\python.exe -c "import sys; print(sys.executable)"
```

预期结果：

- 第一条显示 `Python 3.11.x`；
- 第二条以 `D:\campus-lab-work\.venv\Scripts\python.exe` 结尾。

### 0.9.3 检查锁定的依赖版本

复制并执行完整的一行：

```bat
.venv\Scripts\python.exe -c "from importlib.metadata import version; print('Flask', version('Flask')); print('pytest', version('pytest'))"
```

必须看到：

```text
Flask 3.1.3
pytest 9.1.1
```

D00 暂时不安装 Flask-SQLAlchemy。到 D04 接入 SQLite 数据模型时，新的 `requirements.txt` 和初始化脚本会自动补装它。

### 0.9.4 用 VS Code 打开正确目录

1. 启动 Visual Studio Code。
2. 选择“文件 → 打开文件夹”。
3. 选择 `D:\campus-lab-work`。
4. 左侧资源管理器第一层应直接看到 `requirements.txt` 和 `初始化开发环境.bat`。

如果左侧只看到一个名为 `campus-lab-work` 的子文件夹，说明打开位置高了一层，请重新打开正确目录。

## 0.10 故障排查与恢复

### 0.10.1 找不到 `py` 或 `python`

处理顺序：

1. 关闭当前命令窗口，重新打开命令提示符；
2. 再执行 `py -3.11 --version`；
3. 仍然失败时，重新运行 Python 安装程序，并确认勾选 `Add python.exe to PATH`；
4. 安装完成后重新启动电脑，再检查一次。

### 0.10.2 电脑已有 Python 3.12、3.13 等版本

不必卸载。继续安装 Python 3.11，然后执行：

```bat
py -0p
```

列表中能看到 Python 3.11 的路径后，再运行：

```bat
py -3.11 --version
```

### 0.10.3 `git clone` 很慢或失败

先用浏览器确认 GitHub 仓库能够打开。校园网络暂时不稳定时，使用 0.6.2 节“下载 ZIP”，或者使用教师提前提供的课程资料包。取得资料的方式不同，不影响后续 D00—D16 操作。

### 0.10.4 双击初始化脚本后不知道哪里失败

在命令提示符中执行：

```bat
cd /d D:\campus-lab-work
初始化开发环境.bat
```

窗口会保留错误信息：

- `Failed to create the virtual environment.`：优先检查 Python；
- `Dependency installation failed.`：优先检查网络和 `requirements.txt` 是否存在。

### 0.10.5 提示找不到 `requirements.txt`

说明脚本没有与 `requirements.txt` 放在同一个目录。检查：

```bat
dir D:\campus-lab-work
```

不要在压缩包内部运行脚本，也不要只复制 `初始化开发环境.bat` 一个文件。

### 0.10.6 下载依赖超时

确认浏览器能够联网后，原样重新执行：

```bat
cd /d D:\campus-lab-work
.venv\Scripts\python.exe -m pip install -r requirements.txt
```

安装命令可以重复执行。已经正确安装的指定版本不会因此损坏。

### 0.10.7 `.venv` 创建了一半，之后一直报错

1. 关闭所有正在使用 `D:\campus-lab-work` 的终端；
2. 在文件资源管理器中把 `.venv` 重命名为 `.venv-old`；
3. 再次双击 `初始化开发环境.bat`；
4. 新环境验收通过后，`.venv-old` 才可以删除。

不要删除 `requirements.txt`、`初始化开发环境.bat` 或后续业务代码。

### 0.10.8 PowerShell 提示禁止运行脚本

本课程不要求执行 `Activate.ps1`，也不要求手工激活虚拟环境。所有脚本都直接调用：

```text
.venv\Scripts\python.exe
```

因此请直接使用课程提供的 `.bat` 文件，不要修改 PowerShell 执行策略。

### 0.10.9 文件在桌面或网盘目录中出现路径问题

把课程资料和个人项目移到本手册规定的两个固定目录：

```text
D:\campus-lab-course
D:\campus-lab-work
```

不要放在压缩包、OneDrive 同步目录、聊天软件临时目录或 U 盘中直接运行。

## 0.11 D00 配套文件说明

| 文件 | 作用 | 学生是否自行修改 |
|---|---|---|
| `.gitignore` | 排除虚拟环境、缓存和个人数据库，避免把生成文件当成源码 | 否 |
| `requirements.txt` | 锁定 D00 所需的 Flask 和 pytest 版本 | 否 |
| `初始化开发环境.bat` | 创建 `.venv` 并按依赖清单安装软件包 | 否 |

虚拟环境解决的是“课程项目使用哪套 Python 和依赖”的问题；`requirements.txt` 解决的是“所有同学安装什么版本”的问题；批处理脚本解决的是“每台 Windows 电脑按相同步骤执行”的问题。

## 0.12 D00 文件核对版

本节用于出错时核对。实际课堂操作应优先从 `教学资源/逐步开发代码/D00_S0起点` 复制完整文件，不要依靠手工输入。

### 0.12.1 `.gitignore`

```gitignore
.venv/
__pycache__/
.pytest_cache/
*.py[cod]
instance/
```

### 0.12.2 `requirements.txt`

```text
Flask==3.1.3
pytest==9.1.1
```

### 0.12.3 `初始化开发环境.bat`

```bat
@echo off
setlocal
cd /d "%~dp0"

if not exist ".venv\Scripts\python.exe" (
    py -3.11 -m venv .venv 2>nul
    if errorlevel 1 python -m venv .venv
)

if not exist ".venv\Scripts\python.exe" (
    echo Failed to create the virtual environment.
    pause
    exit /b 1
)

set PIP_DISABLE_PIP_VERSION_CHECK=1
".venv\Scripts\python.exe" -m pip install -r requirements.txt
if errorlevel 1 (
    echo Dependency installation failed.
    pause
    exit /b 1
)

echo Development environment is ready.
pause
```
