# 《校园实验室预约与审批系统》学生实操手册

## 1. 这套手册怎样使用

这是一条从空文件夹到 `dev-v1.0` 的连续开发路线。学生不需要凭空编写代码，也不点击“自动完成”按钮，而是按手册亲手完成以下动作：

```text
了解本步目标
→ 停止上一步程序
→ 从教师源文件复制完整文件
→ 保存到个人工作目录
→ 启动并操作真实页面
→ 对照截图确认结果
→ 运行自动测试
→ 出错时按恢复说明处理
```

个人工作目录统一为 `D:\campus-lab-work`。课程源文件位于 `教学资源/逐步开发代码`，只用于复制和恢复，不直接在其中操作。电脑没有 D 盘时，须在课前选定另一个数据盘，并在全部步骤中保持同一盘符。

## 2. 先完成课前环境

如果电脑尚未准备好，请先完成[《课前准备：学生电脑基本开发环境搭建》](00_课前准备_学生电脑基本开发环境搭建.md)。这份文档从一台普通 Windows 笔记本开始，依次完成 Python 3.11、Visual Studio Code、Git、课程资源目录、个人工作目录和 `.venv` 的安装与验收。

只有环境文档中的八项验收全部通过，才开始 D01。

## 5. 三类文件不要混淆

| 位置 | 用途 | 学生是否修改 |
|---|---|---|
| `D:\campus-lab-work` | 学生个人项目，课堂全部操作发生在这里 | 是 |
| `教学资源/逐步开发代码/Dxx...` | 每一步完成状态，复制来源与救援包 | 否 |
| `教学资源/版本终点核对包/dev-v...` | 七个正式版本的冻结终点 | 否 |

如果某一步无法恢复，先备份个人 `instance/campus_lab.db`，再用对应 D 文件夹核对或整体恢复源文件。

## 7. 教师课堂使用方式

每个 D 步骤按同一节奏实施：

1. 用3—8分钟说明本步解决什么问题、起点是什么、终点是什么；
2. 教师打开完整源文件解释关键结构，不逐行讲解语法；
3. 学生按表格复制完整文件，教师同步演示；
4. 全体启动并对照真实截图检查；
5. 执行本步测试；
6. 少数出错学生直接用本步完整快照恢复，课堂继续推进。

这使教师把注意力放在过程、知识、业务含义和开发经验上，不被随机拼写错误和代码补全问题拖住。
