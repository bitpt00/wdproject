# 校园实验室预约与审批系统（开发教学版）

这是“软件项目开发”课程的贯穿案例。项目采用 Flask、Jinja2、Flask-SQLAlchemy 和 SQLite，学生可以在一台普通笔记本上完成从页面到数据库的完整开发过程。

## 半自动教学平台（非计算机专业课堂推荐）

首个可用原型已经覆盖`S0→dev-v0.1`。学生不需要手写大段代码，但必须逐步完成预测、应用、启动、页面操作、代码观察、手工测试、自动测试、故障判断、恢复和版本冻结。

1. 下载或克隆`main`分支的完整项目，不要只下载某一个旧标签。
2. 双击`启动教学平台.bat`；如果`.venv`不存在，脚本会先在项目目录内创建虚拟环境并安装依赖。
3. 浏览器访问`http://127.0.0.1:8000`，输入本人学号和姓名。
4. 严格按C0—C8顺序完成；学生网站由平台在独立端口启动。
5. 完成后下载个人ZIP证据包，其中包含学习报告、状态记录、测试输出和13文件核对表。

详细说明见[教学平台使用说明](teaching_platform/README.md)和[T05原型详细设计](教学文档/教师用书/T05_S0到V0.1半自动教学平台原型详细设计.md)。当前平台只自动引导第一个版本，V0.2—V1.0继续使用S07—S12讲义和终点包，后续再按T04矩阵扩展。

## 完整系统本机运行

1. 双击 `初始化开发环境.bat`，只在项目目录创建独立的 `.venv`。
2. 双击 `启动系统.bat`。
3. 浏览器访问 `http://127.0.0.1:5000`。

演示账号统一密码为 `123456`：

- 学生：`20260001`
- 审批教师：`T1001`
- 实验室管理员：`A001`

## 七个代码基线

| 标签 | 开发结果 |
| --- | --- |
| `dev-v0.1` | Flask网站骨架与静态原型 |
