# 校园实验室预约与审批系统（开发教学版）

这是面向非计算机专业学生的“软件项目开发”课程贯穿案例。技术路线为 Flask、Jinja2、Flask-SQLAlchemy 和 SQLite，学生在普通 Windows 笔记本上，从空文件夹开始，经过 D00—D16 得到完整系统。

本课程不要求学生独立编写大段代码。每一步提供完整源文件，学生亲手创建目录、复制和替换文件、启动系统、操作页面、观察结果、运行测试并处理常见错误。原“半自动零代码教学平台”方案已经废止，不再作为课程入口。

## 当前主入口

1. 先阅读[学生实操手册总入口](教学文档/学生实操手册/README.md)。
2. 查看[D00—D16开发步骤总矩阵](教学文档/学生实操手册/00_D00到D16开发步骤总矩阵.md)。
3. 从[第1章：D00—D03](教学文档/学生实操手册/01_D00到D03_从空文件夹到V0.1静态原型.md)开始，严格按顺序操作。
4. `教学资源/逐步开发代码`保存每一步完成后的完整代码，是复制来源和课堂恢复包。
5. `教学资源/版本终点核对包`保存七个正式版本终点，用于机械核对。

学生统一在自己的工作目录操作，例如：

```text
C:\campus-lab-work
```

不要直接修改 `教学资源/逐步开发代码` 中的教师源文件。

## 最终系统本机运行

若只需体验最终系统：

1. 双击 `初始化开发环境.bat`，只在项目目录创建独立 `.venv`。
2. 双击 `启动系统.bat`。
3. 浏览器访问 `http://127.0.0.1:5000`。

演示账号统一密码为 `123456`：

- 学生：`20260001`
- 审批教师：`T1001`
- 实验室管理员：`A001`

运行全部测试：双击 `运行测试.bat`，或执行：

```bat
.venv\Scripts\python.exe -m pytest -q
```

最终正确结果为 `34 passed`。
